A note on align and border

The align and border attributes on <img> are obsolete in HTML5, so the W3C validator reports them as errors. To keep every page valid, images use the alt, width and height attributes in the HTML, while alignment and borders come from the CSS classes .align-right, .align-left and .img-border. These classes do the same job as the old attributes.
